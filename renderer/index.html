它做什么

面向影视 DIT、摄影师与剪辑师的素材备份工具： 单次读取素材卡，同时写入多个目标磁盘，逐目标回读哈希校验，并生成可归档的拷卡报告。

  • 单读多写 · 一张卡同时备份到 N 个磁盘
  • SHA-256 / MD5 / SHA-1 / BLAKE2b 双哈希复核，失败自动重拷
  • PDF 拷卡报告 + CSV 全量清单 + 整卡指纹
  • 命名模板、断点续拷、保留时间戳、完成后安全弹出
  • 应用内检查更新，下载后校验 SHA-256 再安装

数据与隐私

全部处理都在本机完成。素材卡以只读方式访问，不做任何写回、移动或删除； 不上传任何文件、路径或哈希。更新功能仅在检查版本时请求你配置的更新源。
